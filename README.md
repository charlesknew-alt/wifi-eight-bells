# Guest Wi-Fi — The Eight Bells

Live at **[wifi.eightbellsbolney.com](https://wifi.eightbellsbolney.com)**.

This is the guest splash page for The Eight Bells, Bolney. After guests join the pub Wi-Fi they land here: follow us, book a table or a room, browse the menu, leave a review, message the pub, or join the newsletter.

It is one of the Kinfold Inns pub software systems — the guest-facing counterpart to the [owner portal](https://owner.kinfoldinns.co.uk) and [manager portal](https://manager.eightbellsbolney.com).

## What it does

- Social follow (Facebook and Instagram)
- ResDiary table booking widget
- Cloudbeds room booking
- Links to menu, rooms, local guide, events, and gift vouchers
- Google review prompt
- Contact form and newsletter (Google Apps Script)
- Opening hours, phone, and directions

## Files

| File | Purpose |
